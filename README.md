A validator for my X quote posts answering @makefunai's newest posts for the make.fun reposts bounty. It reads POSTS.json, checks every entry is an https://x.com/ceokopdesc/status/<id> URL (at most 15), and writes the validated list to the output directory. DRAFTS.md holds the six quote drafts, one per verified pool post.

## Run it

```sh
MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
